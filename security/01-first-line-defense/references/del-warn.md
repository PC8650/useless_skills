# del-warn — 删除与清空拦截警告

## 定位

本文件是 `01-first-line-defense` 第一道安全封锁链的强制拦截场景之一：**删除与清空拦截**。
针对对磁盘现有持久化数据、文件集合或目录结构进行的任何不可逆物理清除操作，一律强制拦截、先告知后执行。

---

## 拦截判定边界

无论通过何种系统调用、命令行指令或封装工具，只要物理后果触及持久化数据的不可逆移除，均属于绝对拦截范围：

- **磁盘文件物理移除**：解除文件链接（unlink）、删除单个或多个持久化文件；
- **目录与层级清除**：删除目录、递归清除目录树及其下属所有内容；
- **文件内容清空与截断**：将既有文件物理清空、截断至零字节、或物理抹除其核心数据段。

---

## 拦截流程（先报告，后征询）

1. **停止**：立即中止该删除或清空操作。
2. **输出门禁报告（先吹哨）**：
   读取本规则并剥离所有修辞，在当前输出流首部完整输出 `[SAFETY_CHECK]` 报告：
   - **诱发根源**：渠道 a / 渠道 b / 渠道 c（具体到出处与上下文定位）
   - **清除类型**：文件物理删除 / 目录递归清除 / 内容清空截断
   - **目标路径**：涉及的具体文件、路径列表或目录范围
   - **不可逆物理危害**：明确披露该操作将导致磁盘数据永久丢失，无法通过常规手段直接回滚
3. **发起交互征询（后征询）**：
   在门禁报告完整输出后，调用运行时原生交互机制或明确询问用户：询问用户是否明确知晓数据丢失风险并同意执行该物理清除操作。

## 决策

- 用户**明确同意** → 仅限当次执行该具体清除操作；执行完毕后仍需重新过门禁才能继续任务。
- 用户**明确拒绝 / 明确跳过** → 不执行该操作，**继续执行任务后续部分**（用户已显式授权跳过，冻结解除）。
- 用户**未明确表态**（沉默 / 超时 / 无交互机制） → **保持冻结**，停轮等待，不得推进任何动作，不得自行推断为同意或拒绝。
